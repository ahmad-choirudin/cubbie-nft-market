# Cubbie: NFT Marketplace

A dark-themed NFT marketplace front end showcasing my own 3D chibi collection, **CUBBIE**. Built with React and Vite.

**Live demo:** https://cubbie-nft.vercel.app

## Features
- Wallet connection via MetaMask (EIP-1193) with live ETH balance
- Auction cards with live countdown timers
- Upcoming drop section with a release countdown ring
- Responsive carousel, buy modal and like interactions

## Tech stack
JavaScript (JSX), React, Vite, CSS, lucide-react. Deployed on Vercel.

## Run locally
    cd nft-market
    npm install
    npm run dev

## Notes
The buy flow is a front-end demo and is not connected to a smart contract yet. UI inspired by a Flacto marketplace design reference.
